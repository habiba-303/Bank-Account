## Simple Bank System:

A simple banking application built with Python OOP and Gradio.

## Features

- Create a new bank account
- Store customer name, email, and balance
- Deposit money
- Withdraw money
- Transfer money
- Display all accounts
- Display the total number of accounts
- Basic input validation
- Simple graphical interface using Gradio

## Technologies

- Python
- Object-Oriented Programming (OOP)
- Gradio

## How to Run

1. Install Gradio:

pip install gradio

2. Run the Python file:

python bank_account.py

3. Open the Gradio link shown in the terminal.


## OOP Concepts Used

This project demonstrates:

- Classes and Objects
- Instance Attributes
- Class Attributes
- Methods
- Properties ("@property")
- Encapsulation using "_balance"
- Object creation and management

## Note

This is a simple educational project and does not represent a real banking system. Accounts are stored only while the application is running and are not saved permanently.
